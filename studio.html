Step-by-step Setup Guide
● Claude.ai (Web / Desktop)
  1. Profile → Settings → Capabilities → turn Create and edit files ON.
  2. Left sidebar → Plugins → "Add" → Upload animated-shorts-kit.zip.
  3. Confirm skill toggle is ON and start new chat.
● Claude Code (Terminal)
  1. Unzip folder to ~/.claude/skills/animated-shorts-kit/.
  2. Or keep inside project root .claude/skills/.
  3. Restart Claude Code session.
● ChatGPT / Custom GPT
  1. Create a Project or Custom GPT.
  2. Upload files: SKILL.md, references/, library/.
  3. Instruct it: "Follow SKILL.md for everything."
